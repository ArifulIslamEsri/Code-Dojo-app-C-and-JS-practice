JavaScript Core Concepts with Examples
1 — Variables & Data Types
Rule of thumb: Use const by default. Use let only when you need to reassign. Never use var in modern JS — it has confusing function scope.
Variables
// const — can't be reassigned
const name = "Ahmad";
const age  = 25;
const isActive = true;

// let — can be reassigned
let score = 0;
score = 10;   // OK

// Data types
const text    = "Hello";       // string
const count   = 42;           // number
const pi      = 3.14;         // number (no float type)
const flag    = false;        // boolean
const nothing = null;         // intentional empty
let   missing;                 // undefined — not yet set

// Template literals (string interpolation)
const msg = `Hello, ${name}! You are ${age} years old.`;
console.log(msg); // Hello, Ahmad! You are 25 years old.
2 — Functions
Three ways to write a function. Arrow functions are shorter and commonly used in modern JS. They don't have their own this — important for OOP.
Functions
// 1. Function declaration (hoisted — can call before definition)
function greet(name) {
  return `Hello, ${name}!`;
}

// 2. Function expression
const add = function(a, b) {
  return a + b;
};

// 3. Arrow function (most common in modern JS)
const multiply = (a, b) => a * b;   // implicit return

const square = n => n * n;           // single param, no parens needed

const fullName = (first, last) => {   // multi-line needs { return }
  const name = `${first} ${last}`;
  return name.toUpperCase();
};

// Default parameters
const welcome = (name = "Guest") => `Welcome, ${name}!`;
console.log(welcome());        // Welcome, Guest!
console.log(welcome("Sara")); // Welcome, Sara!
3 — Arrays & Array Methods
The Big Three: map transforms each item, filter keeps matching items, reduce collapses to one value. These replace most for loops in modern JS.
Arrays
const nums = [1, 2, 3, 4, 5];

// map — transform every element, returns NEW array
const doubled = nums.map(n => n * 2);      // [2,4,6,8,10]

// filter — keep elements that pass the test
const evens = nums.filter(n => n % 2 === 0); // [2,4]

// find — returns FIRST match (or undefined)
const firstBig = nums.find(n => n > 3);     // 4

// reduce — collapse to single value
const total = nums.reduce((acc, n) => acc + n, 0); // 15

// includes, indexOf
nums.includes(3);   // true
nums.indexOf(3);    // 2

// spread operator — copy or merge arrays
const more = [...nums, 6, 7];             // [1,2,3,4,5,6,7]

// Destructuring
const [first, second, ...rest] = nums;
console.log(first, second, rest); // 1  2  [3,4,5]
4 — Objects
Objects
const user = {
  name:  "Ahmad",
  age:   25,
  greet() { return `Hi, I'm ${this.name}`; }
};

// Access
user.name;         // "Ahmad"
user["age"];       // 25

// Destructuring objects
const { name, age } = user;

// Spread — copy/merge objects
const updated = { ...user, age: 26, city: "KL" };

// Optional chaining — safe access
const city = user?.address?.city;  // undefined (no error)

// Nullish coalescing — fallback
const display = user.nickname ?? "No nickname";
5 — Classes & OOP
Classes
class Animal {
  // # means private (modern JS)
  #name;

  constructor(name, sound) {
    this.#name = name;
    this.sound = sound;
  }

  speak() {
    return `${this.#name} says ${this.sound}`;
  }

  get name() { return this.#name; }
}

class Dog extends Animal {
  constructor(name) {
    super(name, "Woof");  // call parent constructor
  }

  fetch(item) {
    return `${this.name} fetches the ${item}!`;
  }
}

const dog = new Dog("Rex");
console.log(dog.speak());        // Rex says Woof
console.log(dog.fetch("ball")); // Rex fetches the ball!
6 — Async / Await & Promises
Golden rule: Always await inside an async function. Use try/catch to handle errors. async/await is just cleaner syntax on top of Promises.
Async/Await
// Fetch data from an API
async function getUser(id) {
  try {
    const response = await fetch(`https://api.example.com/users/${id}`);
    if (!response.ok) throw new Error("User not found");
    const user = await response.json();
    return user;
  } catch (error) {
    console.error("Error:", error.message);
  }
}

// Run multiple requests in parallel (faster!)
async function getMultiple() {
  const [user, posts] = await Promise.all([
    fetch("/api/user").then(r => r.json()),
    fetch("/api/posts").then(r => r.json()),
  ]);
  return { user, posts };
}

8 — Closures & Scope
A closure is a function that remembers the variables from where it was created, even after that outer function has finished running.
Closures
// Counter factory — each call creates its own count
function makeCounter(start = 0) {
  let count = start;         // private to this closure
  return {
    increment() { return ++count; },
    decrement() { return --count; },
    value()     { return count; }
  };
}

const c1 = makeCounter();
const c2 = makeCounter(10);

c1.increment(); // 1
c1.increment(); // 2
c2.increment(); // 11 — completely independent
9 — Error Handling
Try/Catch
function divide(a, b) {
  if (b === 0) throw new Error("Cannot divide by zero");
  return a / b;
}

try {
  const result = divide(10, 0);
  console.log(result);
} catch (err) {
  console.error("Caught:", err.message);  // Cannot divide by zero
} finally {
  console.log("Always runs");
}

// Custom error type
class ValidationError extends Error {
  constructor(field, msg) {
    super(msg);
    this.name = "ValidationError";
    this.field = field;
  }
}
C# Core Concepts with Examples
1 — Variables & Types
C# is statically typed — you declare the type. Use var to let the compiler infer the type (it's still strongly typed, just shorter to write).
Variables & Types
// Explicit types
string  name    = "Ahmad";
int     age     = 25;
double  pi      = 3.14159;
bool    isActive = true;
decimal price   = 9.99m;  // m suffix = decimal literal

// var — compiler infers the type
var city = "Kuala Lumpur";  // string
var num  = 42;              // int

// Nullable types — can hold null
int? nullableAge = null;
string? middle = null;

// String interpolation
string msg = $"Hello, {name}! Age: {age}";

// Constants
const double MaxSpeed = 299792458.0;
2 — Control Flow
Control Flow
// if / else if / else
int score = 75;
if (score >= 90)      Console.WriteLine("A");
else if (score >= 80) Console.WriteLine("B");
else                  Console.WriteLine("C");

// switch expression (C# 8+)
string grade = score switch {
  >= 90 => "A",
  >= 80 => "B",
  >= 70 => "C",
  _      => "F"
};

// for loop
for (int i = 0; i < 5; i++) Console.Write(i + " ");

// foreach
var names = new[] { "Ana", "Ben", "Cara" };
foreach (var n in names) Console.WriteLine(n);

// while
int x = 0;
while (x < 3) { Console.WriteLine(x); x++; }
3 — Methods
Methods
// Basic method
static string Greet(string name) => $"Hello, {name}!";

// Optional parameters
static string Welcome(string name, string title = "Mr") =>
  $"Welcome, {title} {name}";

// Named arguments (any order)
Welcome(title: "Dr", name: "Ahmad");

// out parameter — return multiple values
static bool TryDivide(int a, int b, out double result) {
  if (b == 0) { result = 0; return false; }
  result = (double)a / b;
  return true;
}

if (TryDivide(10, 2, out double r))
  Console.WriteLine($"Result: {r}"); // 5
4 — Classes & OOP
Classes
public class Animal {
  // Auto-properties
  public string Name  { get; }
  public string Sound { get; set; }

  public Animal(string name, string sound) {
    Name  = name;
    Sound = sound;
  }

  public virtual string Speak() => $"{Name} says {Sound}";
}

public class Dog : Animal {
  public Dog(string name) : base(name, "Woof") { }

  public override string Speak() =>
    $"{base.Speak()} (tail wagging)";

  public string Fetch(string item) =>
    $"{Name} fetches the {item}!";
}

var dog = new Dog("Rex");
Console.WriteLine(dog.Speak());       // Rex says Woof (tail wagging)
Console.WriteLine(dog.Fetch("ball")); // Rex fetches the ball!
5 — Interfaces
Interface = a contract. Any class that implements it MUST provide those methods. This is how C# achieves loose coupling — you code against the interface, not the implementation.
Interfaces
public interface IShape {
  double Area();
  double Perimeter();
}

public class Circle : IShape {
  private double _radius;
  public Circle(double r) => _radius = r;
  public double Area()      => Math.PI * _radius * _radius;
  public double Perimeter() => 2 * Math.PI * _radius;
}

public class Square : IShape {
  private double _side;
  public Square(double s) => _side = s;
  public double Area()      => _side * _side;
  public double Perimeter() => 4 * _side;
}

// Works with ANY IShape — no change needed when adding new shapes
static void PrintInfo(IShape shape) {
  Console.WriteLine($"Area: {shape.Area():F2}");
}
6 — LINQ
LINQ (Language-Integrated Query) lets you query collections like a database query. It's one of C#'s most powerful features — like JS array methods but far more expressive.
LINQ
var numbers = new List<int> { 1,2,3,4,5,6,7,8 };

// Where = filter
var evens = numbers.Where(n => n % 2 == 0); // [2,4,6,8]

// Select = transform (like JS .map)
var squared = numbers.Select(n => n * n);

// OrderBy, OrderByDescending
var sorted = numbers.OrderByDescending(n => n);

// First, FirstOrDefault
var firstBig = numbers.FirstOrDefault(n => n > 5); // 6

// Any, All, Count
bool hasEven  = numbers.Any(n => n % 2 == 0);  // true
bool allPositive = numbers.All(n => n > 0);      // true
int  bigCount = numbers.Count(n => n > 4);       // 4

// Sum, Average, Max, Min
int    total = numbers.Sum();       // 36
double avg   = numbers.Average();  // 4.5

// Chaining
var result = numbers
  .Where(n => n > 2)
  .Select(n => n * 10)
  .OrderBy(n => n)
  .ToList();  // [30,40,50,60,70,80]
7 — Async / Await
Async/Await
using System.Net.Http;

// async method returns Task or Task<T>
public static async Task<string> GetDataAsync(string url) {
  using var client = new HttpClient();
  try {
    string response = await client.GetStringAsync(url);
    return response;
  }
  catch (HttpRequestException ex) {
    Console.WriteLine($"Error: {ex.Message}");
    return string.Empty;
  }
}

// Run tasks in parallel
var (t1, t2) = (GetDataAsync("url1"), GetDataAsync("url2"));
await Task.WhenAll(t1, t2);

// Calling from Main (C# 7.1+)
static async Task Main() {
  var data = await GetDataAsync("https://api.example.com");
  Console.WriteLine(data);
}
8 — Generics
Generics let you write code that works with any type. Instead of writing a separate method for int, string, double — write one method with <T>.
Generics
// Generic method
static T GetFirst<T>(List<T> list) =>
  list.Count > 0 ? list[0] : default;

GetFirst(new List<int> { 1,2,3 });     // 1
GetFirst(new List<string> { "a","b" }); // "a"

// Generic class
public class Box<T> {
  private T _value;
  public Box(T value) => _value = value;
  public T Open()      => _value;
  public string Info() => $"Box contains: {_value}";
}

var intBox    = new Box<int>(42);
var stringBox = new Box<string>("hello");
Console.WriteLine(intBox.Info()); // Box contains: 42
9 — Exception Handling
Exceptions
public static double Divide(double a, double b) {
  if (b == 0) throw new DivideByZeroException("b cannot be 0");
  return a / b;
}

try {
  double result = Divide(10, 0);
}
catch (DivideByZeroException ex) {
  Console.WriteLine($"Math error: {ex.Message}");
}
catch (Exception ex) {
  Console.WriteLine($"Unexpected: {ex.Message}");
}
finally {
  Console.WriteLine("Cleanup done");
}

// Custom exception
public class AgeException : Exception {
  public int ProvidedAge { get; }
  public AgeException(int age)
    : base($"Invalid age: {age}") => ProvidedAge = age;
}
