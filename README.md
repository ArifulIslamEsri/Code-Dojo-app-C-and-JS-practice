# Code Dojo — JS & C# Daily Practice

A daily practice app for JavaScript and C#: short lessons, a daily challenge, quizzes and a cheat sheet.

**Live site:** https://code-dojo-app-c-and-js-practice.vercel.app

## What's inside

- Today's challenge
- JavaScript and C# lessons
- Quizzes for each language, with review and retry
- Cheat sheet

## Run locally

Open `index.html` in any browser. No build step needed.
